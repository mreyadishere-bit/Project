# Smart Road — Beginner Starter (نسخة تعليمية عملية)

هذه نسخة **تعمل محليًا على الكمبيوتر** من نظام سلامة طرق ذكي وليست منظومة تنبؤ حوادث حقيقية.

## 1. ماذا ستفعل؟
- تحليل فيديو طويل أو كاميرا اللابتوب باستخدام YOLO26 (Nano/Small/Medium) مع تتبع المركبات والمشاة وإشارات المرور.
- كشف وعدّ الأجسام المرئية في الإطارات المختارة، وتتبّع IDs تقديري ومخططات وتقرير CSV. **الأجسام الفريدة ليست مؤكدة، ولا يقيس سرعة السيارة بالكيلومتر/ساعة.**
- استقبال بلاغات مشاكل الشوارع وحفظها في SQLite.
- عرض البلاغات ونقاط فيديوهات قمت بتحديد موقعها يدويًا على خريطة.
- جلب طقس **الوقت الحالي** من Open-Meteo للإحداثيات التي تدخلها.
- مقارنة أقصر طريق بطريق آخر في **شبكة طرق افتراضية** من صنعنا. ليست ملاحة على الطرق الحقيقية.
- استقبال بيانات LDR وحساس IR من ESP32 عبر شبكة Wi-Fi محلية **اختياري**.

## 2. تجهيز Windows من الصفر
1. ثبّت Python 3.11 من https://www.python.org/downloads/ — فعّل Add Python to PATH إن ظهر.
2. ثبّت VS Code من https://code.visualstudio.com/ (اختياري، للتعديل على الملفات).
3. فك ضغط ZIP في أي مجلد عادي على الكمبيوتر.
4. افتح `setup_windows.bat` (بالضغط مرتين) لعمل البيئة الافتراضية وتنزيل الحزم. أول تنزيل لـ PyTorch وUltralytics قد يكون كبيرًا ويحتاج إنترنت.
5. افتح `run_windows.bat`. سيظهر الرابط المحلي `http://localhost:8501` تلقائيًا. لو المتصفح لم يفتح، اكتبه يدويًا.
6. في أول تحليل فيديو، سينزّل Ultralytics وزن `yolo26n.pt` مرة واحدة فقط.

إذا لم تعمل ملفات BAT افتح Terminal داخل مجلد المشروع ونفذ:
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
إذا كان PowerShell يمنع تشغيل activate، استخدم Command Prompt واكتب `.venv\Scripts\activate.bat` بدلًا منه.

## 3. أول تجربة واقعية
1. صوّر بنفسك فيديو فيه سيارات أو لعبة سيارات (في مكان آمن ومسموح؛ تجنب إظهار الوجوه واللوحات).
2. من التطبيق > تحليل الفيديو > اختر مسار MP4 على جهازك أو ارفع ملفًا أو استخدم كاميرا الكمبيوتر > ابدأ التحليل.
3. راقب المربعات وTrack IDs حول السيارات والمشاة والرسمة البيانية المباشرة، ثم نزّل CSV من النتائج.
4. من الشريط الجانبي أدخل إحداثيات المكان (يمكنك معرفة الإحداثيات بضغط مطوّل على الخريطة في الهاتف)، ثم أرسل بلاغ حفرة أو عائق **تجريبي**.
5. افتح تبويب الخريطة، ثم الطقس، ثم مقارنة الطرق. الطقس الحالي ليس بالضرورة طقس وقت تصوير الفيديو.

### ماذا لا يفعل الإصدار الأول؟
لا يكتشف الحفر تلقائيًا بنموذج YOLO العام. لا يحسب سرعات حقيقية، ولا يتأكد من near-miss، ولا يتنبأ بمعدل وقوع الحوادث، ولا يقدم توجيه ملاحي حقيقي. ذلك يحتاج بيانات تدريب ومعايرة كاميرا وتقييم علمي.

## 4. إضافة الحساسات كخطوة ثانية (اختياري)
**المكونات:** ESP32 DevKit، حساس قرب IR يعمل عند 3.3V، LDR (مقاومة ضوئية)، مقاومة 10kΩ، Breadboard، أسلاك Jumper، كابل USB، لابتوب، لعبة سيارة، ومجسم شارع من كرتون. لا تستخدم جهدًا أعلى من 3.3V على مداخل ESP32.

### التوصيل (افصل USB أثناء التوصيل)
- LDR أحد أطرافه إلى 3V3 والطرف الآخر إلى GPIO34.
- مقاومة 10kΩ بين GPIO34 و GND. هذه دائرة تقسيم جهد؛ إضاءة أعلى تعطي ADC أكبر غالبًا.
- حساس IR: VCC إلى 3V3 و GND إلى GND و OUT إلى GPIO27. **تأكد من أن نسختك تدعم 3.3V وتخرج إشارة لا تتجاوز 3.3V.**
- ضع الحساس أمام سيارات لعب، واستخدم كشاف هاتفك ثم غطِّ LDR لاختبار الفرق.

### إعداد Arduino IDE
1. نزّل Arduino IDE من https://www.arduino.cc/en/software
2. من Preferences > Additional Boards Manager URLs أضف رابط ESP32 الرسمي: https://espressif.github.io/arduino-esp32/package_esp32_index.json
3. Boards Manager > ابحث عن `esp32` وثبّت **esp32 by Espressif Systems**.
4. Tools > Board > ESP32 Dev Module (أو اسم لوحتك)، ثم اختَر المنفذ COM الصحيح.
5. افتح `hardware/smart_road_esp32.ino` وعدّل اسم وكلمة مرور Wi-Fi وعنوان IP اللابتوب والإحداثيات.
6. الكمبيوتر وESP32 يجب أن يكونا على نفس شبكة Wi-Fi الخاصة بك.
7. قبل التحميل شغّل خادم الاستقبال كما في الخطوة التالية.

### خادم استقبال بيانات ESP32
افتح Command Prompt داخل مجلد المشروع وشغّل:
```bat
.venv\Scripts\activate.bat
set ROAD_DEMO_KEY=change-this-secret
python -m uvicorn receiver:app --host 0.0.0.0 --port 8000
```
استخدم `ipconfig` لمعرفة IPv4 المحلي للكمبيوتر (مثل 192.168.1.100) وبدله في كود ESP32. تأكد من أن API key مطابق بين الطرفين. يمكنك تغيير قيمة المفتاح من القيمة الافتراضية في كليهما. **لا تفتح المنفذ 8000 للإنترنت، واستخدم شبكة خاصة موثوقة فقط.** قد يحتاج Windows Firewall للسماح باتصال داخلي.

حمّل ملف `.ino` على ESP32 ثم افتح Serial Monitor بسرعة 115200. ترى `HTTP status = 200` عند نجاح إرسال القراءة. في واجهة Streamlit افتح تبويب الحساسات واضغط تحديث. لاحظ أن رقم الـ ADC ليس قياس lux ولا يقيّم سلامة الطريق بمفرده.

## 5. تطوير المشروع بشكل علمي
**الأسبوع 1:** تصوير 10 فيديوهات قصيرة مرخّصة وتوثيق ما يظهر فيها ومراقبة أخطاء الكشف.
**الأسبوع 2:** 3 أنواع بلاغات وموقع تجريبي واضح على الخريطة.
**الأسبوع 3:** إدخال الطقس ووضع مقارنة طريق على شبكة وهمية.
**الأسبوع 4:** عمل مجسم الطريق وإضافة حساس IR + LDR بقطعة ESP32 واحدة.
**الأسبوع 5:** تدريب نموذج إضافي للحفر من بيانات مسموح بها؛ راجع الترخيص وعدّل صيغة YOLO، وقيّم على صور لم يَرها النموذج أثناء التدريب.
**الأسبوع 6:** near-miss يحتاج tracking ونقاط مرجعية ومعايرة زمن ومكان؛ قم بالتحقق اليدوي ولا تسوّق اكتشافًا مبنيًا على تلامس مستطيلات الصور كأنه شبه حادث مؤكد.
